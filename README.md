# 🎮 Gesture Controlled Running Game using OpenCV

🖐️ This project allows users to play running games like **Subway Surfers** using hand gestures instead of a keyboard or mouse. The system detects real-time hand movements through a webcam and maps them to in-game actions such as jump, slide, and left/right movement.

---

## 🚀 Features
- Real-time hand gesture detection  
- Hands-free game control  
- Smooth and responsive gameplay  
- Beginner-friendly implementation  

---

## 🛠️ Technologies Used
- Python 🐍  
- OpenCV (Computer Vision)  
- MediaPipe (Hand Tracking)  

---

## ⚙️ How It Works
📷 The webcam captures live video input.  
🖐️ Hand gestures are detected and tracked in real time.  
🎮 Gestures are converted into keyboard actions to control the game.
